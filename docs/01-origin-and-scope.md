# 1. 프로젝트 출발점과 범위

## 1.1 출발점

- 채용 결과 공유 서비스 **합합**(팀 프로젝트)의 가입·로그인·마이페이지 흐름을 바탕으로 가상 요구사항을 세웠습니다. 요구사항은 *"가입 후 선택적으로 본인확인을 수행하고 계정에 확인 상태를 기록한다"*입니다.
- 처음에는 팀 서버 코드의 **개인 실습 브랜치**에서 설계·구현·검증했습니다. 이 저장소는 그 결과물 가운데 **본인이 작성한 부분만** 독립 실행 프로젝트로 옮긴 것입니다.
- 이 기능은 합합에 도입하기로 확정된 기능이 아닙니다.

## 1.2 팀 서비스에 붙였을 때 지킨 원칙 (이 저장소에도 그대로 반영)

| 원칙 | 이유 |
|---|---|
| 기존 소셜 로그인·회원 생성 흐름과 **로그인 응답 구조를 바꾸지 않는다** | 이미 운영 중인 앱 연동을 깨지 않기 위해 |
| 본인확인 상태는 **내 정보 조회 API에 필드만 추가**해서 노출한다 | 하위 호환 (기존 클라이언트에 영향 없음) |
| 미확인이어도 기존 기능을 막지 않는다 | 선택형 기능 |
| 실습 기능(모의 기관, 테스트 로그인, 데모 화면)은 **실습 프로필에서만** 동작한다 | 운영 환경으로 새지 않게 |
| 기존 보안 설정을 전역적으로 풀지 않는다 | 데모 화면 경로만 별도 필터 체인으로 공개 |
| 탈퇴 처리의 기존 확장 지점(정리기)에 연결한다 | 인증 대기 중 탈퇴 처리 |

## 1.3 이 저장소에서 바꾼 것

팀 코드를 포함하지 않기 위해, 본인확인 기능이 기대는 기반을 **최소한으로 새로 작성**했습니다.

| 영역 | 팀 서비스에서 | 이 저장소 |
|---|---|---|
| 로그인 | 카카오·애플 소셜 로그인 + 리프레시 토큰 | **테스트 회원 로그인만** (`POST /api/v1/auth/test-login`), 액세스 토큰만 발급 |
| 회원 | 서비스 회원 모델 | 최소 `Member` (로그인 키, 이름, 이메일, 상태, 본인확인 상태) |
| 토큰 차단 | Redis(로그아웃 블랙리스트, 탈퇴 표시) | **Redis 없음**. 요청마다 DB에서 회원이 활성 상태인지 확인 |
| 내 정보 응답 | 기존 필드 + 본인확인 필드 2개 | 이름, 이메일 + 본인확인 필드 2개 |
| 실습 격리 | `lab` 프로필 | 저장소 자체가 실습 전용. **기동 안전장치**(DB·외부 기관 주소가 localhost가 아니면 기동 중단)는 유지 |
| 테스트 키 | — | 저장소에 개인키를 두지 않음. 테스트 직전 Gradle 태스크가 생성 |

**그대로 옮긴 것:** 본인확인 도메인 전체(상태 모델, API 3개, 동기화·취소·만료 규칙, 서명 검증, 감사 로그), 모의 인증기관, 실습 PKI, E2E, 운영 지표 SQL, 문서 자동화 도구, 문서.

## 1.4 공통 응답·오류 형식

```json
// 성공
{ "status": 200, "code": "MEMBER_INFO_FETCHED", "message": "회원 정보 조회에 성공했습니다.", "data": { ... } }
// 실패
{ "status": 404, "code": "IDENTITY_VERIFICATION_NOT_FOUND", "message": "본인확인 요청을 찾을 수 없습니다." }
```

- 비즈니스 실패는 `ErrorCode` enum에 상수를 추가하고 `BusinessException`으로 던집니다. `GlobalExceptionHandler`가 이를 위 형식으로 바꿉니다.
- 인증 실패(401)와 권한 없음(403)은 Spring Security 핸들러가 같은 형식으로 응답합니다.
- Controller와 Swagger 문서는 분리합니다. Swagger 어노테이션은 `XxxApiDocs` 인터페이스에 두고, Controller가 그 인터페이스를 구현합니다.

## 1.5 패키지 구조

```
src/main/java/idvlab
├── common/         공통 응답 봉투, 오류 코드, 예외 처리, Swagger 설정
├── auth/           JWT, 보안 설정, 테스트 로그인
├── member/         최소 회원 모델, 내 정보·탈퇴, 탈퇴 정리 확장 지점
├── verification/   본인확인 (엔티티·상태, API, 서비스, 외부 기관 연동, 서명 검증, 감사 로그)
└── lab/            기동 안전장치, 데모 화면
lab/                모의 인증기관, 실습 PKI, E2E, 운영 지표 SQL, 문서 도구, 실행 스크립트
```
